Projetos em Destaque

Projetos desenvolvidos para aplicar conhecimentos em desenvolvimento frontend, backend, APIs, streaming, integração de serviços e interfaces responsivas.

Stream Box

Plataforma de entretenimento desenvolvida com React e TypeScript, integrada à API do TMDB para descoberta e exibição de filmes e séries.

O projeto possui catálogo de conteúdos, pesquisa, categorias, página de detalhes, trailers, interface responsiva e uma área de TV ao vivo utilizando fontes públicas/licenciadas de transmissão compatíveis com HLS.

Também foram implementados player de vídeo, seleção de canais, categorias de conteúdo, notícias, entretenimento e esportes, além de adaptação da interface para celular, tablet e desktop.

ClimaPulse

Dashboard meteorológico interativo desenvolvido com React e TypeScript.

A aplicação utiliza a API do OpenWeather para apresentar informações climáticas em tempo real, além de integração com Leaflet para visualização geográfica.

O sistema possui geolocalização automática, pesquisa de cidades, estados e países, mapas interativos, métricas climáticas e informações dinâmicas de localização.

Sobre Mim

Sou Wallisson Elizeu, desenvolvedor Full Stack com foco em desenvolvimento web e aplicações modernas.

Tenho experiência prática com desenvolvimento frontend utilizando React, TypeScript, JavaScript, HTML e CSS, além de desenvolvimento backend utilizando Node.js, Express e APIs REST.

Nos meus projetos, trabalho com integração de APIs externas, consumo e tratamento de dados, autenticação, bancos de dados, mapas, geolocalização, players de vídeo e aplicações responsivas.

No Stream Box, por exemplo, trabalhei com integração da API do TMDB, organização de conteúdos, pesquisa, categorias, reprodução de vídeo através de HLS e desenvolvimento de uma experiência de TV ao vivo responsiva.

Estou constantemente estudando novas tecnologias e desenvolvendo projetos práticos para aprimorar minhas habilidades e construir soluções cada vez mais completas.
