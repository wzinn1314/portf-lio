Stream Box

Plataforma de streaming desenvolvida com React e TypeScript, integrada à API do TMDB para busca e exibição de filmes e séries. O projeto possui catálogo de títulos, pesquisa, detalhes dos filmes, trailers e interface responsiva inspirada em plataformas modernas de streaming.

ClimaPulse

Dashboard meteorológico interativo em tempo real desenvolvido com React e TypeScript com integração à api do OpenWeather, integrado com Leaflet. O projeto oferece geolocalização automática, navegação por mapa e busca por cidades, estados e países com exibição detalhada de métricas climáticas e bandeiras dinâmicas.
